# ML Fieldbook · 机器学习实验志

一个本地运行的机器学习基础学习平台。它不追求课程数量，而是把「读一点、动手试、被问题检验、留下反思」连成一条可以回看的学习路径。

首版包含一条纵向切片：

**线性回归 → 梯度下降 → 过拟合 → 正则化 → 逻辑回归 → 模型评估 → 决策树与集成 → 神经网络**

每个概念都包含图形直觉、必要的数学表达、符号与词汇工具台、可运行代码、一个交互实验和三道带误解反馈的练习题。另有一份 72 条、7 类的基础概念库，覆盖数据、数学、优化、泛化、经典算法、深度学习与工程实践，并为每一类标注推荐读本。学习记录、答题记录与日志只保存在本机的 SQLite 数据库中。

## 功能

- **沉浸式开始页**：根路径 `/` 用实时 Three.js 回归场景呈现训练/验证样本、预测平面与残差，主题对应线性回归、过拟合和正则化；数据水流、3D 拟合平面动态水纹、玻璃态章节与残差标注对应「数据 → 模型 → 泛化」，辅以标题流光、指针光场与磁吸按钮。点击「开始学习」经过连续的场景过渡进入 `/today`。3D 引擎按需加载，提供 WebGL 不可用时的视觉降级，并在减少动态偏好下使用静态场景。
- **今日工作台**：把下一步拆成一条 52 分钟的 6 步学习脚本——先判断、精读一个小节、动手计算、交互实验、做一道题、留下证据；每一步都可以点选查看详情，当前步骤会同步到学习轨道。已完成的小节在当天保持钉住，不跳到下一节。今日目标、本周节奏、学习路径与最近活动仍来自真实事件。
- **全局快速跳转**：按 `Ctrl/⌘ + K` 搜索页面、学习章节与 72 个概念词条；支持上下方向键、回车进入和 Esc 关闭。
- **起点诊断**：8 道短判断覆盖先修、损失、泛化与正则化；记录答案、1–5 级置信度、提示与耗时，提交后给出有理由的入口建议和逐题复盘。诊断不写入练习证据，也不生成掌握率。
- **完整概念教学**：9 个引导章节、27 个学习小节。每节从具体问题出发，包含原理与 KaTeX 公式推导、三步数值例题、Python 代码逐段解读、常见误解纠正、三点小结和自测解析；另配符号表、术语表、交互实验与原始资料链接。
- **基础概念库**：72 条可检索词条，按数据、数学、优化、泛化、经典算法、深度学习、工程实践七类组织；每条都有定义、公式或说明、直觉、常见误解、相关词和 Python 示例。每类附两条推荐读本，支持关键词检索、分类筛选与独立词条页。
- **可探索实验（全宽实验舞台）**：每章一个联动实验，共 9 个；所有数值逻辑是带单元测试的纯函数（`frontend/src/components/experiments/analysis.ts` 至 `analysis4.ts`）。下列为前三个实验，其余见后文各轮更新。
  - 线性回归：数据空间与参数空间双向联动。可拖动数据点（也支持键盘方向键），残差可显示为平方面积；右侧是 MSE(w,b) 热力图与等高线，可点击或拖动选参数，带负梯度箭头；梯度下降可调学习率并逐步动画，刻度上标出稳定上限 2/λmax，超过会真实发散。
  - 过拟合：1–9 阶误差扫描曲线（点击选阶）；同一阶数在 14 个重抽样数据集上的拟合曲线显示方差；60 次蒙特卡洛的偏差²/方差/噪声分解柱图。
  - 正则化：log α 验证曲线（标出测试最低点）与 9 个系数的收缩路径，两张图都可直接拖动 α。
  - 实验记录同一概念每天只写入一次，重复记录会明确提示本次参数未再次保存，不重复累计学习时长。
- **置信度校准**：学习进度页按 1–5 级置信度展示真实正确率，标出「有把握却答错」的次数；少于 3 次作答的档位以描边柱提示样本不足。练习反馈在高把握答错、低把握答对时给出对应提示。
- **理解检验**：作答前记录 1–5 级置信度，提交后给出解释与可能误解；不提前泄露答案。
- **学习进度**：基于真实事件的时长、完成小节、正确率、未修正错题与活动记录，不合成虚假的「掌握率」。
- **学习日志**：按日期记录「弄懂了什么 / 哪里还说不清 / 下一步」，自动附上当天学习事件与最近七天节奏；有未保存修改时切换日期会先确认，取消不会丢失草稿。
- **响应式与可访问性**：桌面使用横向悬浮导航与非对称学习舞台，移动端使用浮动底栏与横向步骤卡；保留键盘焦点、滚动进度、跳转链接、弹层焦点约束与减少动态偏好支持。正文与控件使用放大后的阅读字号。

## 快速开始

环境要求：Node.js 20+、Python 3.10+，以及 [uv](https://docs.astral.sh/uv/)（或可用的 pip）。

```bash
# 1. 安装前端依赖
npm install

# 2. 创建 Python 虚拟环境并安装后端依赖
uv venv .venv --python 3.10
uv pip install --python .venv/bin/python -r backend/requirements.txt

# 3. 构建前端
npm run build

# 4. 启动服务（API 与前端共用一个端口）
PYTHONPATH=backend/src .venv/bin/uvicorn mlearning.main:app --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000> 查看开始学习页，点击「开始学习」进入今日工作台；也可直接访问 `/today`。

数据库会在首次启动时自动创建：`backend/data/mlearning.db`。学习内容在 `content/concepts.json`，基础概念库在 `content/foundations.json`，诊断题库在 `content/diagnostic.json`。

| GET | `/curriculum` | 7 阶段学习路径：目标、产出、引导章节、配套词条、里程碑与基于真实记录的阶段状态 |
| GET | `/concepts` | 概念摘要列表 |
| GET | `/concepts/{slug}` | 概念正文、完整教学小节、来源、符号/词汇/算法工具台 |
| GET | `/foundations` | 72 条基础概念、七类结构、分类读本与延伸资料 |

| POST | `/progress/events` | 记录小节完成、实验完成或开始学习 |

## 设计取舍

- **不显示虚假的掌握度。** 完成小节只证明阅读行为；正确率只描述当前作答。平台保留原始证据，让学习者自己判断下一步。
- **实验必须改变结论。** 每个实验都直接操作模型参数、数据或流程，并同时显示训练与测试误差，而不是播放动画。
- **不使用假数据。** 空状态就是空状态，下一步、周图和错题都来自真实接口。
- **本地优先。** 没有账户、云同步或遥测。删除 `backend/data/mlearning.db` 会清空全部学习记录，操作前请先备份。
- **诊断是入口校准，不是考试。** 8 道题只支持一次起点建议；推荐规则与理由公开，逐题保留答案、置信度、提示和耗时，原始记录不可变。
- **首版范围克制。** 九个引导章节配一张 72 条的概念地图，不做课程市场、AI 导师或社交功能。
- **字号优先可读。** 正文 15–16px，控件与元信息按 6 级字号阶梯统一；信息层级仍靠字重、留白与色彩建立。

## 已知限制

- 单用户、无身份验证，仅适合在可信的本机环境运行。
- 内容以 JSON 静态维护；新增引导概念需要同时提供完整教学小节、来源、题目和工具台，新增词条需要公式/代码/相关词，并通过启动校验。
- 概念库中的 Python 示例用于解释算法；完整运行通常需要自行安装 NumPy 与 scikit-learn，深度学习条目另需 PyTorch。平台本身不执行这些代码。
- 间隔复习只显示待复习数量的数据接口，尚未实现完整的调度算法。
- 过拟合实验中的「平行数据集」来自已知的真实函数加噪声，用于演示偏差-方差分解；正则化实验直接用测试集选 α 是为了可视化，实验内已注明真实流程应使用交叉验证。
- 起点诊断目前是固定 8 题的规则建议，不是自适应测验；重新诊断会新增一条记录并保留旧结果。
- 日志不支持 Markdown/附件导出，仅保存在本地数据库。

产品与学习模型的完整设计见 [PROJECT.md](PROJECT.md)。
