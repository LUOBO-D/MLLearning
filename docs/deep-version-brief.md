## 1. 顶尖专家在这里会做什么，而你没有要求

这里的"专家"指两类人：做可探索解释（explorable explanation）的交互设计师，和研究学习效果的学习科学研究者。

- **让图形本身可以操作。** 把滑块换成直接拖拽：拖动数据点、拖动参数空间里的点。滑块只做精调和键盘入口。
- **联动视图。** 同一个模型同时出现在"数据空间"（点和拟合线）和"参数空间"（损失等高线）里，改其中一边，另一边同步变化。学生要理解的是这两边的对应关系，单看任何一边都学不到。
- **把隐藏的量画出来。** 残差画成真实的平方面积，因为 MSE 就是这些面积的平均。偏差与方差靠重复抽样后的一组拟合曲线来显示，而不是一句结论。
- **把一个参数扫一遍。** 只看当前阶数时的误差，看不出过拟合；把 1–9 阶全部扫一遍，画出训练/测试误差曲线（U 形），再标出当前位置，才看得到。正则化同理，需要验证曲线和系数路径图。
- **校准，而不只是正确率。** 产品已经在每次作答前记录 1–5 级置信度，但从未把它用起来。学习科学里，"高置信错误"最值得复习（hypercorrection effect）。专家会画一张校准图：每个置信等级的实际正确率。
- **先修 CSS 债务再加东西。** 5 个样式表约 1.6 万行，层层覆盖。审计中已发现旧侧栏规则覆盖新目录，导致"本章目录"逐字竖排。

## 2. 他们会用什么具体方法和工具

| 问题 | 方法 / 工具 |
| --- | --- |
| 交互可视化 | SVG + 自写比例尺（本项目零依赖即可）；更大规模时用 D3 / Observable Plot。拖拽用 Pointer Events + `setPointerCapture`，键盘用方向键步进 |
| 参数空间 | 在网格上解析计算 MSE(w,b)，用 canvas 画热力图、等高线（marching squares）；梯度下降轨迹逐帧动画 |
| 偏差-方差 | 已知真实函数 + 带种子的伪随机噪声做蒙特卡洛重复抽样，计算 bias²、variance、噪声 σ² 三项分解 |
| 正则化 | Ridge 闭式解在 log α 网格上扫描，得到验证曲线与系数路径 |
| 学习证据 | 置信度-正确率校准表；只展示真实计数，样本少时明确标注"样本不足" |
| 动效 | 统一缓动令牌；`prefers-reduced-motion` 降级；CSS View Transitions / 进入动画只用 transform 和 opacity |
| 质量保障 | Vitest 覆盖数学函数（数值对照闭式解），pytest 覆盖新接口，Playwright 多宽度截图与溢出检查，axe-core 无障碍扫描 |

## 3. 顶尖工程师如何让复杂任务有条不紊

1. **先审计，再动手。** 跑起服务，在 1440/390 宽度截全部路由，列出真实问题，而不是凭印象改。
2. **数学与界面分离。** 所有数值逻辑写成纯函数，先写测试，再接界面。图表只负责把数据映射成像素。
3. **共享图形原语。** 一个 `LabPlot` 坐标系组件，供散点图、误差曲线、路径图共用，避免三套坐标系代码。
4. **按价值排序，时间盒执行。** 先做价值最高的：三个实验的深度化，然后是校准视图，最后是视觉打磨。每完成一块就跑构建和测试。
5. **可回滚。** 项目不是 Git 仓库，开工前已打包备份：`~/Documents/MLLearning-backup-20261118-1212.tar.gz`。
6. **验证闭环。** 每个改动都在真实浏览器里截图检查，最后统一跑测试、构建、axe 和多宽度溢出检查。

## 4. 可以直接学习借鉴的研究与网页

- **MLU-Explain**（Amazon）：线性回归、偏差-方差、正则化的滚动叙事交互讲解。<https://mlu-explain.github.io/>
- **Distill.pub**：联动视图与可操作图形的标杆；另见 Olah & Carter, *Research Debt* (2017)。<https://distill.pub/>
- **Seeing Theory**（Brown University）：概率统计可视化，回归一章可以直接拖动数据点。<https://seeing-theory.brown.edu/>
- **R2D3, A Visual Introduction to Machine Learning**：用滚动驱动的叙事解释过拟合。<http://www.r2d3.us/>
- **Bret Victor, *Explorable Explanations* (2011)** 与 **Bartosz Ciechanowski** 的交互长文：可操作图形的写作方法。
- **学习科学**：Roediger & Karpicke (2006) 检索练习；Butterfield & Metcalfe (2001) 高置信错误更容易被纠正；Dunlosky et al. (2013) 学习策略效果综述；Bjork 的"合意困难"（desirable difficulties）。
- **泛化研究**：Belkin et al. (2019) *Reconciling modern ML practice and the bias–variance trade-off*（double descent），用于在过拟合实验的注释里说明经典 U 形曲线的适用范围。
